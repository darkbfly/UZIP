# 目录结构

```
UZIP/
├── doc/obsidian/          ← 本知识库（Obsidian Vault）
├── src/UZIP2/
│   ├── UZIP2.sln
│   └── UZIP2/
│       ├── UZIP2.csproj   # .NET Framework 4.5 WPF
│       ├── App.xaml(.cs)  # 应用入口（空壳 Application）
│       ├── MainWindow.*   # 主 UI + 拖拽/压缩解压流程
│       ├── Setting.cs     # USetting + 枚举 + Password
│       ├── Config.cs      # AppSettings 读写封装
│       ├── Tools.cs       # UTool：路径、7z、文件工具
│       ├── Language.cs    # UI 提示文案
│       ├── UHotKey.cs     # 全局热键
│       ├── SimulateInput.cs
│       ├── Mypassword.cs / MyPasswords.cs
│       ├── *Window.xaml*  # 结果/选择路径/键盘/调试/确认
│       ├── Properties/    # AssemblyInfo、Settings、Resources
│       └── bin/Debug/7-Zip/  # 运行时附带 7-Zip（构建产物侧）
└── .gitignore
```

## 源码文件职责速查

| 文件 | 职责 |
|------|------|
| `MainWindow.xaml.cs` | UI 事件、模式切换、拖拽分派、调用压缩/解压 |
| `Setting.cs` | 全局状态 `USetting`、配置属性、`AppModes`/`RunStatus`/`ExtractPath`、`Password` |
| `Config.cs` | `ExeConfigurationFileMap` 读写 `.config` |
| `Tools.cs` | 路径校验、拆分密码、7z 路径、通用文件操作 |
| `UHotKey.cs` | 热键注册 |
| `SelectOut*.xaml` | 选择输出路径相关 UI |
| `ResultWindow.xaml` | 独立结果窗口 |
| `KeyBoard.xaml` | 屏幕键盘/密码输入辅助 |
| `DebugWindow.xaml` | Debug 模式窗口 |
| `YesNo.xaml` | 确认对话框 |
