# 项目概览

## 是什么

**UZIP2**（界面署名 `UZip2.22 by Farkaway`）是 Windows 桌面压缩/解压工具：拖拽文件到主窗口，按工作模式自动压缩或解压。实际编解码委托 **7-Zip**（内置 `7-Zip/7z.exe` 或用户自定义路径）。

| 项 | 值 |
|----|----|
| 技术栈 | C# / WPF / .NET Framework 4.5 |
| 输出类型 | `WinExe` |
| 程序集 | `UZIP2` |
| 来源标注 | 52pojie.cn（见 `USetting.UZip`） |

## 核心能力

- **三种工作模式**：自动 / 仅解压 / 仅压缩（`AppModes`）
- **拖拽驱动**：主窗口接受文件/文件夹列表后分派压缩或解压
- **密码体系**：密码纸、密码本、解压时贴入、迷你模式收集（`Password` / `RunStatus`）
- **解压输出路径**：文件旁、浏览、多组自定义目录（`ExtractPath`）
- **覆盖策略**：对应 7z `-aos` / `-aoa` / `-aou` / `-aot`
- **热键 / 置顶 / 结果窗 / Debug 窗**

## 运行时依赖

- 默认：程序目录下 `7-Zip\7z.exe`（`UTool` 拼路径）
- 可选：设置里勾选自定义 `7z.exe`

## 配置落盘

| 文件 | 用途 |
|------|------|
| `Config/UZip.config` | 主设置（`USetting.UConfig`） |
| `Config/PasswordPage.config` | 密码纸 |
| `Config/PasswordNote.config` | 密码本 |
| `Compress.log` | 压缩记录 |
