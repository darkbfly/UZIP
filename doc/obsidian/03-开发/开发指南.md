# 开发指南

## 环境

| 项 | 建议 |
|----|------|
| IDE | Visual Studio（打开 `src/UZIP2/UZIP2.sln`） |
| 目标框架 | .NET Framework **4.5** |
| JDK/Maven | 无关（本仓库为 C# WPF） |

本机若需命令行构建，用对应 VS Developer Prompt / MSBuild 指向该 `.csproj`。

## GitHub Actions 发版

工作流：`.github/workflows/release.yml`

| 触发 | 做法 |
|------|------|
| 打 tag | `git tag v1.0.0` → `git push origin v1.0.0` |
| 手动 | GitHub → Actions → **Release** → Run workflow → 填版本号 |

产物：`UZIP2-v*-win.zip`（含 `UZIP2.exe`、`UZIP2.exe.config`、`7-Zip\7z.exe`），自动挂到对应 GitHub Release。

本地等价打包：

```powershell
msbuild src\UZIP2\UZIP2\UZIP2.csproj /t:Rebuild /p:Configuration=Release /p:Platform=AnyCPU
```

## 本地运行

1. 打开 `src/UZIP2/UZIP2.sln`
2. 配置 `Debug`，启动项目 `UZIP2`
3. 确认输出目录存在可用的 `7-Zip\7z.exe`（或设置自定义路径）
4. 首次运行会在 exe 旁使用 `Config\` 下配置文件

## Debug 模式

- `ShowDebug`：仅改配置文件开启后，设置页才显示 Debug 开关
- `DebugMode`：开发者模式，可打开 `DebugWindow`

## 改代码前
