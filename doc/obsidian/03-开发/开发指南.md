# 开发指南

## 环境

| 项 | 建议 |
|----|------|
| IDE | Visual Studio（打开 `src/UZIP2/UZIP2.sln`） |
| 目标框架 | .NET Framework **4.5** |
| JDK/Maven | 无关（本仓库为 C# WPF） |

本机若需命令行构建，用对应 VS Developer Prompt / MSBuild 指向该 `.csproj`。

## 本地运行

1. 打开 `src/UZIP2/UZIP2.sln`
2. 配置 `Debug`，启动项目 `UZIP2`
3. 确认输出目录存在可用的 `7-Zip\7z.exe`（或设置自定义路径）
4. 首次运行会在 exe 旁使用 `Config\` 下配置文件

## Debug 模式

- `ShowDebug`：仅改配置文件开启后，设置页才显示 Debug 开关
- `DebugMode`：开发者模式，可打开 `DebugWindow`

## 改代码前

按 [[首页]] 场景表先查知识库对应模块页，再下钻源码。

## 改代码后

按「知识库同步」规则回写 `doc/obsidian/`：模块页、索引、开发指南中与行为相关的描述。
