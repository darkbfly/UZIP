# 7z调用

## 职责

定位 `7z.exe`、组装解压输出路径、配合主窗口发起压缩/解压进程。编解码不自实现，全部走 7-Zip CLI。

## 关键路径

- `src/UZIP2/UZIP2/Tools.cs` — `UTool`（含默认 `"…\7-Zip\7z.exe"`）
- `src/UZIP2/UZIP2/MainWindow.xaml.cs` — 自定义路径校验、覆盖参数、UI 绑定

## 7z 路径解析

1. 若 `Customize7z` 且路径合法（存在且以 `7z.exe` 结尾）→ 用自定义路径
2. 否则 → `BasePath + "7-Zip\\7z.exe"`

设置页双击路径框可浏览选择；`BCustomize7zPath_Check` 负责校验与写回 `USetting`。

## 覆盖模式（解压）

| UI | 参数 |
|----|------|
| 跳过已存在 | `-aos` |
| 全部覆盖 | `-aoa` |
| 自动重命名 | `-aou` |
| 已存在则重命名 | `-aot` |

对应 `USetting.ExtractCoverMode`。

## 相关能力（主流程侧）

- 解压过滤 / 压缩过滤数组
- 完成后删除源文件、建新文件夹 / 按名建夹
- 7z 格式隐藏文件列表（仅 7z）

改命令行参数时，搜索 `MainWindow.xaml.cs` 与 `Tools.cs` 中启动进程处，并回归测三种 `AppModes`。
