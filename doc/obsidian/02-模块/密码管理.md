# 密码管理

## 职责

解压加密档案时的密码来源与编辑：密码纸、密码本、废纸篓、迷你模式收集、从文件名拆分密码等。

## 关键类型

| 符号 | 位置 | 说明 |
|------|------|------|
| `Password` | `Setting.cs` | 密码列表封装，数量不设上限 |
| `USetting.PWPaper` | 密码纸 | 持久化到 `PasswordPage.config` |
| `USetting.PWNote` | 密码本 | 持久化到 `PasswordNote.config` |
| `USetting.PWRecycle` | 废纸篓 | 内存列表，关闭软件清除 |
| `UTool.SplitString` | `Tools.cs` | 按分隔符从文件名提取密码 |
| `KeyBoard` | `KeyBoard.xaml` | 屏幕键盘辅助输入 |

## 密码本导入 / 导出

- 入口：密码管理 → 密码本页 →「导入」「导出」
- 格式：UTF-8 文本，**每行一个密码**（与编辑框一致）
- 导入：写入编辑框，需再点「确定」才持久化到 `PasswordNote.config`
- 导出：导出当前编辑框内容

## 运行态约束

`RunStatus.EditPassword` / `MiniMode` / `ExtractFile` 等状态下，主窗口限制「能否解压 / 贴入 / 改设置」。改密码流程时先对照 `RunStatus` 注释。
