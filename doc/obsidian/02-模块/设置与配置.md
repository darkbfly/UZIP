# 设置与配置

## 职责

- `Config`：按路径打开 `.config`，读写 `AppSettings`
- `USetting`：静态全局配置门面 + 运行时状态（文件列表、取消标志、密码对象等）

## 关键路径

- `src/UZIP2/UZIP2/Config.cs`
- `src/UZIP2/UZIP2/Setting.cs`

## 配置文件

相对 `ApplicationBase`：

| 对象 | 路径 |
|------|------|
| `UConfig` | `Config\UZip.config` |
| `UPageConfig` | `Config\PasswordPage.config` |
| `UNoteConfig` | `Config\PasswordNote.config` |

新增配置项：在 `USetting` 增加 get/set（`GetConfig`/`SetConfig` + 默认值），并在 `MainWindow.ControlInitialize` / 对应 Click 事件双向绑定。

## 开机启动

- 配置键：`AutoStart`（默认关）
- UI：设置 → 主程序 →「开机自动启动」
- 实现：`USetting.ApplyAutoStart` 写/删 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 项 `UZip2`（值为当前 exe 路径）
- 启动时按配置回写注册表，避免勾选状态与注册表漂移

## 监听文件夹

- 配置：`WatchFolderEnabled` / `WatchFolderPath` / `WatchFolderOutPath`（仅设置页持久化）
- UI：设置 → 主程序 →「监听文件夹（仅解压）」+ 路径 + 输出目录
- 行为：目录内出现压缩包则自动解压；普通文件忽略
- 实现：`FolderWatch` → 排队 → `StartJobFromFileList(OnlyExtract)`
- CLI `watch`：会话态路径/输出，**不写**共享 `UZip.config`；`-p` 仅进内存密码纸（不持久化）
- 命令行：`UZIP2.exe watch <文件夹> [-o 目录] [-p 密码] [-q]`（见 [[开发指南]]）

## 关键枚举

| 枚举 | 含义 |
|------|------|
| `AppModes` | Auto / OnlyExtract / OnlyCompress |
| `RunStatus` | Normal、EditSetting、EditPassword、MiniMode、ExtractFile… |
| `ExtractPath` | File / Browse / Customize1–8… |

## 常用配置键（节选）

`AppMode`、`WindowOnTop`、`AutoStart`、`WatchFolderEnabled`、`WatchFolderPath`、`WatchFolderOutPath`、`Customize7z`、`Customize7zPath`、`ExtractOutMode`、`ExtractCoverMode`、`UseHotKey`、`DebugMode`、`ShowDebug`、`DeleteFinishFile`、`CreateNewFolder`…

完整列表以 `Setting.cs` 中属性为准。
